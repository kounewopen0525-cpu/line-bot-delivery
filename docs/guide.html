▶ エラー別 解決ガイド
!
command not found: claude

インストール後にターミナルを再起動していない、またはPATHが通っていない場合に発生。

🍎 MAC / LINUX # ターミナルを再起動 or： source ~/.bashrc source ~/.zshrc
🪟 WINDOWS # PowerShellを管理者で再起動 $env:Path = [System.Environment]::GetEnvironmentVariable("Path","Machine")
💡 それでも解消しない場合はインストールをやり直す
!
Authentication required / ログインできない

サブスクリプションが有効でない、またはセッションが切れている場合に発生。

再ログイン $ claude > /login # ブラウザが開いたら再度承認する
⚠ 無料プランではログインできません。Pro以上が必要です
!
Rate limit exceeded / 使用制限に達した

短時間に大量のリクエストを送ると発生。しばらく待つか、翌日にリセット。

状態確認 > /status # 現在のプランと使用状況を確認
💡 Maxプランにアップグレードすると制限が大幅に緩和されます
!
Permission denied / ファイルを操作できない

起動ディレクトリ外のファイルにアクセスしようとした場合や、権限不足の場合に発生。

🍎 MAC / LINUX # 対象フォルダで起動する cd /path/to/your/project claude
🪟 WINDOWS # 管理者としてPowerShellを起動後 cd C:\path\to\project claude
💡 プロジェクトのルートフォルダで claude を起動するのがベストプラクティス
!
Node.js / npm のバージョンエラー

Claude CodeはNode.js 18以上が必要。古いバージョンの場合に発生。

バージョン確認 & アップデート node --version # v18.0.0 以上が必要 # nvmでアップデート（Mac/Linux） nvm install --lts && nvm use --lts

🔴 エラー早見表

  • command not found → 再起動
  • Auth required → /login
  • Rate limit → 時間を置く
  • Permission denied → cd先変更
  • ENOENT → パス確認
  • Network error → 接続確認

🔵 困ったときのコマンド

  • /status
  • /login
  • /help
  • Ctrl+C
  • exit
