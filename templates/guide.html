Claude Code
インストール超詳細ガイド

コマンド1つ。5分で完了します。

1
Mac｜インストールコマンド
Windows｜インストールコマンド
STEP 1

ターミナルを開いてコマンドを貼り付ける

ターミナルの開き方
  1. Command + Space でSpotlightを開く
  2. 「ターミナル」と入力してEnter

以下のコマンドをコピーしてターミナルに貼り付けてEnterを押す

curl -fsSL https://claude.ai/install.sh | sh
STEP 2

インストール完了まで待つ（30秒〜1分）

Enterを押すと文字が流れます。これはインストール中なので待ちましょう。

ターミナル
$ curl -fsSL https://claude.ai/install.sh | sh

Installing dependencies...
▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓░░░░░ 75%

✓ Claude Code successfully installed!
Run 'claude' to get started.
✓ 「Claude Code successfully installed!」と表示されたら完了です。
STEP 1

PowerShellを開いてコマンドを貼り付ける

PowerShellの開き方
  1. タスクバーの検索で「PowerShell」と入力
  2. 「Windows PowerShell」をクリック
⚠ PowerShell（青い画面）で実行してください。コマンドプロンプト（黒い画面）では動きません。

以下のコマンドをコピーしてPowerShellに貼り付けてEnterを押す

irm https://claude.ai/install.ps1 | iex
STEP 2

インストール完了まで待つ（30秒〜1分）

Windows PowerShell
PS C:\Users\YourName> irm https://claude.ai/install.ps1 | iex
Downloading Claude Code... Installing...
▓▓▓▓▓▓▓▓▓░░░░░░ 60%

✓ Claude Code successfully installed!
⚠ 完了後、PowerShellを一度閉じて新しく開き直してください（重要！）

5
エラーが出たときの対処法
❗ command not found: claude
ターミナルを一度完全に閉じて、新しく開き直してから再度「claude」と入力してください。 PowerShellを一度完全に閉じて、新しく開き直してから再度「claude」と入力してください。
❗ permission denied
コマンドの先頭に「sudo 」を追加して実行：
sudo curl -fsSL https://claude.ai/install.sh | sh
Macのパスワードを入力（入力中は何も表示されませんが正常です）
❗ ブラウザが開かない
ターミナルに表示されているURL（https://claude.ai/auth?code=...）をコピーしてブラウザのアドレスバーに貼り付けてアクセスしてください。
❗ node: command not found
Node.jsが未インストールです。nodejs.org からNode.js（LTS版）をインストールしてから再実行してください。
